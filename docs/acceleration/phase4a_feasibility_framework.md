# Cheap experiment-feasibility gate

**Selection checklist, not an experiment certificate.** Reuse existing source receipts, hashes, identity contracts, stage controls, trial journals and inference feasibility guards. This checklist adds an earlier decision point; it does not replace the proof compiler or enable real execution.

Screen mechanism and documentation first. Retain every candidate and a reason for rejection/deferment. Commission a small metadata/source-only pilot only after owner family approval. Then review a complete contract before freeze or any performance. A high score cannot override an unresolved mandatory gate.

| Mandatory gate | Cheapest decisive question | Required evidence before full-design advancement |
| --- | --- | --- |
| Source | Is there a versioned, source-defined event denominator, including negative/withdrawn/modified cases? | Publisher scope, stable IDs, revision/duplication rules, retrieval limits and missingness receipts |
| Timing | Can public knowledge be distinguished from effective/action/filing/ingestion dates? | Original time representation/channel, timezone evidence, historical reconstruction flag; separately approved bound if exact publication is unknown |
| Identity | Can an event-time recipient map to the exact traded class without current-survivor filtering? | Dated parent/subsidiary/class/stable-ID/exchange chain, ambiguous mappings retained |
| Population | Is the source frame complete enough to define treatment and controls? | Fixed pre-return inclusion rules, all exclusions/missing cases, historical denominator and coverage audit |
| Execution | Can every required security path and terminal transition be represented? | Calendar, nominal prices/actions/payment/terminal semantics, certified identity-preserving route; no unsupported holding disappearance |
| Controls | Is the comparison credible for the estimand? | Ex-ante observable controls, anticipation/selection/confounding analysis, contamination and placebo plan; causal language only with identification |
| Inference | Is the declared null test defensible under the expected dependence? | Unit/group geometry, repeated-issuer/agency/calendar clustering, common shocks and few-cluster limits; named assumptions and failure worlds |
| Power / resolution | Could the fixed design answer its economic question? | Usable independent count bounds, minimum-p feasibility, frozen synthetic calibration, materiality semantics and noise sensitivity; no real candidate returns used for planning |
| Trial budget | Can all choices and failure attempts fit a predeclared ceiling? | One reviewed family/transform, controls, multiplicity and stop rules; count every attempt; no inherited/reset performance allowance |

Verdicts: REJECT_CHEAPLY for a documented fatal obstacle; DEFER_FOR_BOUNDED_EVIDENCE for unresolved fields; READY_FOR_OWNER_DESIGN_REVIEW only when all mandatory evidence is reviewed. None authorizes execution. Unknown is not pass, sample-row count is not effective sample size, and a sum of ordinal scores is not a gate certificate.

## Common scorecard

Use sixteen named criteria, fixed in [the selection plan](phase4a_plan.md), and the same rubric for every family: **0** documented major obstacle, **1** plausible but certification needed, **2** documented useful primary-source capability, **null** unknown. These are qualitative triage judgments, not measured alpha probabilities. Every score needs a rationale and evidence reference; source capability can justify 2 even while trading timing remains unresolved. Do not score unknown counts as zero, or make totals depend on a historical return.

Recommendation means “best next bounded evidence question,” not “winner” or certified family. Report known-score subtotal and unknown count separately. Do not compare a numerator with different hidden missingness. All candidates stay unavailable for design advancement until actual mandatory gates pass.

## Reusable event receipt fields

Preserve `event_id`, `event_type`, economic event/effective date, nullable observed public-known time and channel, raw timestamp/timezone evidence, separately modeled bound/policy hash, issuer/security/class, agency/counterparty, original contract/application/case identifiers, original economic amount/currency/amount type, entity/relationship effective spans, source URL/hash/version and acquisition time. Record identity/relationship confidence as evidenced statuses, not arbitrary AI probabilities. Retain revisions and failed/unresolved mappings; a later API correction cannot rewrite what was publicly known earlier.

Government procurement must distinguish initial awards, options/modifications, obligations, ceilings, outlays and termination; none automatically measures surprise or incremental issuer revenue. FDA approval coverage cannot manufacture absent rejection decisions. Enforcement announcements cannot manufacture untreated firms or assume random assignment. Use these questions as early falsification, not licenses to acquire a broad corpus.

## Stop boundaries

Reject or defer when source/public timing, identity, controls or effective independent counts cannot support the question at bounded cost. Require a new owner decision for paid sources or changed scope; do not buy data. No graph, causal platform, strategy, real compiler/engine activation, ranking, price-return query, performance, Nexus/Aurora or paper/live operation belongs to selection. A failed family remains institutional evidence and does not trigger automatic idea generation.
