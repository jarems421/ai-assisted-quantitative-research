Add public deterministic boundary tests; run targeted/public/full suites, source/freeze reconciliation, report/presentation and preservation checks. Commit verified evidence and closure, push main, observe CI, then stop. FDA ADVANCE/REDESIGN/REJECT is a feasibility verdict, not a claim about alpha. If FDA fails, merger enforcement may receive one separately instructed bounded pass; no automatic launch, new families or endless selection loop after the original three.
