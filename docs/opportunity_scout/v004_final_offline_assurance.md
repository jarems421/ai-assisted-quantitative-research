## Findings and integration recommendation

Two substantive R1 assurance gaps were reproduced with fictional inputs before correction:

1. **Complete-line rollback:** deleting a complete journal suffix preserves a valid hash-chain prefix. After deleting a pending CONSUMED suffix, a new handle could start the same slot again. Removing a RESULT suffix also lost the recorded completion without a tamper error. An internal hash chain alone does not authenticate its latest head.
2. **Submission reselection after exception:** if `finish()` raised before creating its attempt directory, the original handle retained ownership and could submit a different recording. The interrupted first recording was not archived. Reopening the run was blocked, but the original handle was still retryable.

`SCOUT_V004_OFFLINE_JOURNAL_R2` writes an exclusive, fsynced per-event witness **before** each journal append and compares the exact witness bytes and complete witness set on every load. A missing suffix, changed witness or orphan write-ahead witness stops the run. The first finish submission relinquishes handle ownership before validation/locking; its raw stdout/stderr are saved before evaluation. An exception cannot reopen selection or reset the consumed slot. Recording metadata is also frozen and replay-checked. New R2 journals are required; old journals are not rewritten.

Seven targeted regressions cover both rollback points, write-ahead interruption, invalid submission tags, evaluation interruption/raw preservation and witness mutation. Three tests use actual cooperating **local Python processes** to establish lock exclusion, race behavior and stale-lock behavior after a killed holder. They run separately from the Scout suite's process-launch guard; no child launches Claude, calls a provider or reads accounts. The source remains offline-only.

**Integration recommendation:** do not integrate the original reviewed SHA as though no substantive defects were found. The corrected offline implementation is a candidate for integration into its investigation branch after passing CI and focused independent re-review of the R2 witness/finish changes.
